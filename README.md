# DigitX Pro

E-commerce website for **DigitX Pro** ([@digitxpro](https://www.instagram.com/digitxpro)) — a modern store for smart living, high-fidelity audio (hybrid ANC earbuds, studio headphones, Bluetooth speakers), AMOLED smartwatches, fast-charging power banks, esports gaming gear, and mobile accessories.

## Tech stack

- Vite + React 19 + TypeScript
- Tailwind CSS v4
- Zustand for cart state
- React Router

## Getting started

```bash
npm install
npm run dev
```

The dev server runs at `http://localhost:5173/`.

## Scripts

```bash
npm run dev      # start dev server
npm run build    # typecheck + production build
npm run lint     # oxlint
npm run preview  # preview the production build
```

## Brand & Assets

- Brand identity aligned with `@digitxpro` on Instagram.
- Product, category, and hero banners feature curated high-resolution studio & lifestyle photography.
